
# واسط خواندنی TSETMC — پیش‌نویس

## هدف
صفحهٔ تشخیص بازار به‌جای درخواست مستقیم از مرورگر، داده‌های عمومی TSETMC را از Worker موجود سهمینو می‌گیرد. این تغییر فعلاً فقط صفحهٔ تشخیص مستقل را به واسط متصل می‌کند؛ مسیر قیمت‌گذاری اصلی اپ تا زمان پذیرش میدانی دست‌نخورده می‌ماند.

## مسیر عمومی
`GET /api/v1/public/tsetmc`

منابع مجاز:
- `resource=instrument-search&symbol=...` → جست‌وجوی نماد
- `resource=closing-price&instrumentId=...` → اطلاعات قیمت پایانی
- `resource=daily-history&instrumentId=...` → تاریخچه روزانه

مقصد بالادستی ثابت است: `https://cdn.tsetmc.com/api`. کلاینت اجازهٔ ارسال URL یا مسیر دلخواه ندارد. شناسه فقط ۸ تا ۲۵ رقم و نماد فقط از مجموعهٔ محدود نویسه‌های فارسی/لاتین/عدد پذیرفته می‌شود.

## محافظت‌ها
- CORS فقط محدودیت مرورگر است، نه احراز هویت یا محافظت در برابر فراخوانی مستقیم؛ این endpoint عمومی و فقط‌خواندنی است. پیش از انتشار عمومی/ترافیک بالا باید محدودسازی نرخ در Cloudflare فعال و پایش شود.
- فقط GET؛ بدون نوشتن، سفارش، دسترسی به D1 یا اطلاعات سبد.
- CORS فقط برای مبدأ دقیق `https://raminhashemi1.github.io`.
- مسیرهای بالادستی allowlist شده؛ جلوگیری از SSRF و redirect.
- timeout دوازده‌ثانیه‌ای و حداکثر یک تلاش مجدد فقط برای خطای شبکه/timeout.
- پاسخ فقط JSON؛ حداکثر ۲ MiB با خواندن جریانی محدود؛ بدون cache.
- خطاهای 429، HTTP، timeout، شبکه و JSON نامعتبر جداگانه گزارش می‌شوند.
- هیچ شناسه‌ای به‌صورت خودکار انتخاب یا در سبد ذخیره نمی‌شود.

## وضعیت انتشار
- کد در شاخهٔ `feature/tsetmc-readonly-worker-proxy-v1` آمادهٔ بازبینی است.
- **هنوز روی Cloudflare deploy نشده است.** پس از بازبینی و ادغام PR، مالک باید workflow دستی `Sahamban approved free pilot deploy (no paid checkout)` را با عبارت تأیید دقیق `DEPLOY_PILOT_NO_PAYMENTS` اجرا کند.
- پس از deploy، ابتدا health و آزمون proxy با نماد عمومی فولاد انجام شود؛ سپس صفحهٔ تشخیص و ۷ نماد آزمایش شوند.
- اگر Worker هنوز deploy نشده باشد، نسخهٔ جدید صفحه از endpoint جدید پاسخ نخواهد گرفت؛ تا زمان deploy، نسخهٔ قبلی صفحه قابل استفاده است.
- این واسط تضمین پایداری یا مجوز رسمی استفاده از منبع TSETMC نیست. پاسخ قیمت فقط دادهٔ عمومی است و به‌تنهایی توصیه خرید/فروش یا قیمت زندهٔ تأییدشده محسوب نمی‌شود.
