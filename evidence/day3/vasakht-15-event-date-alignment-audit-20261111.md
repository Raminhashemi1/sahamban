## Root cause: wrong comparison boundary

The previous 5/15 tally compared each adjustment event's `pClosingNotAdjusted` with the *same-date* daily `pClosing`. The event's pre-adjustment reference instead agrees with the *preceding chronological daily row* in **14/15 events**. The same-date value is not necessarily a pre-event reference: some events fall on trading days, when the day's closing price differs from both pre- and post-adjustment reference prices.

**Verified 15-event results:**
- Old, invalid-as-general-rule same-date comparison: **5/15** agreement.
- Correctly separated preceding-date comparison: **14/15** agreement.
- Residual: **2021-01-19** has event pre-adjustment **60,754 IRR** versus preceding daily close **60,750 IRR**, difference **+4 IRR**. Its event post-adjustment is **59,910 IRR**; the next chronological daily row closes at **59,910 IRR**. This does not explain the four-rial discrepancy and must not be rounded away.
