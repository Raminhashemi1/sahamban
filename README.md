# سهام‌بان (Sahamban)

برنامهٔ موبایل‌پسند برای مشاهدهٔ دارایی‌های واردشده از CSV/XLSX کارگزاری، مدیریت ریسک و تحلیل قیمت. بدون دریافت رمز کارگزاری.

## وضعیت انتشار

- شاخهٔ `main` نسخهٔ عمومی ۴۷ است.
- قابلیت‌های نسخهٔ آزمایشی ۴۸ در شاخهٔ `feat/portfolio-live-prices-v48` و PR #1 نگهداری می‌شوند؛ **هنوز منتشر یا ادغام نشده‌اند**.
- دریافت واقعی قیمت پایانی TSETMC از شبکهٔ GitHub Actions و مرورگر Chromium آزمایشی به timeout برخورد کرده؛ نتیجهٔ موفق دادهٔ واقعی **تأیید نشده** است.
- همهٔ آزمون‌های کد، گزارش با دادهٔ شبیه‌سازی‌شده و آزمون ۱۹ دارایی نمونه از دادهٔ واقعی کاربر جدا هستند.

## ایمنی داده

- دادهٔ واقعی فایل کارگزاری در `localStorage['sahamban-broker-holdings-v1']` می‌ماند و با تحلیل ریسک و نمونه‌های آن یکی نیست.
- نسخهٔ ۲ این داده به **ریال** است؛ نسخهٔ قدیمی ۱ فقط هنگام خواندن در حافظه از تومان به ریال تبدیل می‌شود و رکورد قدیمی بازنویسی نمی‌شود.
- هیچ به‌روزرسانی قیمت نباید تعداد سهم یا میانگین خرید را تغییر بدهد. دریافت قیمت‌ها در `sahamban-broker-live-quotes-v1` جدا ذخیره می‌شود.
- قیمت پایانی درج‌شده در فایل کارگزاری ممکن است قدیمی باشد؛ گزارش آفلاین مبتنی بر فایل، «قیمت روز تأییدشده» نیست.
- در صورت نامعتبر/قدیمی بودن قیمت حتی یک نماد، جمع ارزش روز جدید منتشر نمی‌شود.
- گزینهٔ «پشتیبان‌گیری از دارایی‌های واقعی» یک فایل JSON فقط برای نگهداری شخصی دانلود می‌کند؛ هیچ رمز، شناسهٔ کاربری یا اطلاعات ورود لازم نیست.

## آزمون

در Node.js و Chromium:

```bash
node tests/smoke.cjs
node tests/sw-offline.cjs
node tests/market-validation.cjs
node --test tests/portfolio-live.test.cjs
node tests/browser.cjs
```

آزمون مرورگر به Playwright نیاز دارد؛ GitHub Actions آن را تهیه می‌کند و نیازی به اجرای دستی روی گوشی نیست.

پایش ارتباط واقعی در `tests/tsetmc-connectivity.cjs` انجام می‌شود، اما این probe حتی با وضعیت خروج موفق به معنای تأیید قیمت زنده نیست؛ خروجی `INTEGRATION BLOCKED/UNVERIFIED` یا `OFFICIAL GATEWAY BLOCKED/UNVERIFIED` نشانهٔ عدم تأیید است.

## شروط انتشار نسخهٔ ۴۸

۱. پاسخ واقعی با قیمت پایانی **ریالی** و تاریخ معتبر و قابل تکرار از منبع مناسب گرفته شود؛ دادهٔ شبیه‌سازی‌شده کافی نیست.
۲. اتصال از مرورگر و شبکهٔ واقعی محل استفاده از برنامه (و سیاست CORS) آزمون شود.
۳. قرارداد داده، مجوز استفاده و انتشار/بازنشر قیمت برای کاربری نهایی بررسی شود.
۴. حفظ داده‌های ذخیره‌شدهٔ قبلی و سازگاری نسخه‌ها، به‌ویژه ۱۹ سهم واردشده روی گوشی، تأیید شود.
۵. تمام CI های نسخهٔ مورد انتشار سبز باشند؛ سپس PR ادغام و برنامه منتشر شود.
