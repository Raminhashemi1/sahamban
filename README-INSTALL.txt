سهام‌بان — نسخه آماده انتشار آزمایشی وب‌اپ (PWA)

این فایل لینک اینترنتی نیست. کل محتویات همین پوشه را بدون پوشه والد در ریشه یک سرویس میزبانی HTTPS رایگان، مانند Netlify Drop بارگذاری کنید.
پس از انتشار، لینک HTTPS ایجاد می‌شود.
اندروید: در Chrome سایت را باز کنید و از منو Install app یا Add to Home screen را بزنید.
آیفون: در Safari سایت را باز کنید، Share سپس Add to Home Screen و Add را انتخاب کنید.
هشدارها با درخواست کاربر بررسی می‌شوند و پس‌زمینه فعال نیستند. اتصال TSETMC در گوشی و امکان دسترسی بین‌دامنه‌ای آزمایش نشده است.
برای استفاده تجاری از داده‌های بازار باید مجوز مربوط بررسی شود.
